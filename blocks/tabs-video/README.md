# tabs-video

Custom **tabs** block. Purpose: centered underline tab bar; each panel shows text (H2, paragraph, optional CTA) beside an autoplaying looping muted video in a dark rounded box with a pause/play toggle.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per tab. Cell 1: tab label. Cell 2: H2, paragraph(s), optional CTA link, and a link to the panel MP4 video (the video link is removed from the text and played in the media box). Only the active tab video plays, and only while the block is on screen.

## Supported variations

No variations.
