# carousel-hotspot

Custom **carousel** block. Purpose: horizontal carousel of tall product photos with (+) hotspot buttons that open product info cards (name, color, View product link); prev/next arrows and a progress bar.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide. Cell 1: product photo. Cell 2: one group per hotspot, each starting with a heading (H5 product name), followed by an optional position paragraph with x/y percentages measured from the image top-left (e.g. "40% 60%", "40, 60" or "x: 40, y: 60"), a color paragraph and a "View product" link. Hotspots without a position get default positions.
