# carousel-video

Custom **carousel** block. Purpose: horizontal carousel of portrait (9:16) video cards with poster, play icon and title overlay; clicking a card opens the video in a fullscreen modal player; prev/next arrows and a progress bar.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide. Cell 1: poster image. Cell 2: title (H5) and a link to the MP4 video. Non-video links fall back to normal navigation.

## Supported variations

No variations.
