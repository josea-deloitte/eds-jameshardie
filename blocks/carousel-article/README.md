# carousel-article

Custom **carousel** block. Purpose: horizontal carousel of white article cards (landscape image, linked title with arrow, category pill links); prev/next arrows and a progress bar.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide. Cell 1: article image. Cell 2: H3 title linked to the article, then a paragraph with one or more category links (rendered as outlined pills).

## Supported variations

No variations.
