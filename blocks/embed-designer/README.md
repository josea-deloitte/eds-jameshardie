# embed-designer

Custom **embed** block. Purpose: lazy-loaded iframe of the Hover home exterior designer (600px tall on mobile, 800px from 1024px) with a centered light footer bar for attribution links; a plain link to the designer shows until the iframe loads.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One cell: link to the Hover designer embed-container URL (https://hover.to/designer/embed-container?...). Any additional links (e.g. the Hover attribution link) are rendered in the footer bar. An optional heading sets the iframe title.

No variations.
